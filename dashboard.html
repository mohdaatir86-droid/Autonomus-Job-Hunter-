AI form-fill assistant (iPhone Safari)
Install the bookmarklet below, then open a job application page in Safari and tap the bookmark. It fills supported fields only; it never submits.
Beta
  1. Copy the bookmarklet code below.
  2. In Safari, bookmark any page, open Bookmarks → Edit that bookmark, and replace its URL with the copied code (starting with javascript:).
  3. Open the employer application form in Safari, tap the bookmark, and enter your Job Hunter portal token when prompted.
  4. Review all populated fields. The assistant will not click Submit or bypass CAPTCHA/OTP.

Works only on ordinary visible fields and compatible Safari pages. Some portals block bookmarklets or use protected embedded forms; use their normal application flow if so. Your token is requested by the bookmarklet and is not saved on the employer website.
